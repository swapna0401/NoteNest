# NoteNest

NoteNest is a modern student resource sharing web app where users can upload, search, and manage study materials like notes, PDFs, and PPTs.

## Features

* User Authentication
* Upload Study Resources
* Search & Filter Notes
* Bookmark Important Files
* Responsive UI

## Tech Stack

* HTML
* CSS
* JavaScript
* Firebase

## Run Project

```bash
git clone https://github.com/swapna0401/NoteNest.git
cd NoteNest
```

Open `index.html` using Live Server in VS Code.

## Firebase Setup

* Enable Authentication
* Create Firestore Database
* Enable Storage
* Add Firebase config in `firebase.js`
